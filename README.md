# HR-Analytics

## Problem Statement

This Power BI dashboard aims to provide a comprehensive overview of employee attrition within the company. It provides insights into the total number of employees, attrition rate, and the distribution of attrition across various demographics, including department, salary, year of hire, age, education level,gender, etc.

By visualizing this data, the dashboard empowers HR personnel and company leadership to:

    Identify trends and patterns in employee attrition.
    Gain insights into the specific employee segments experiencing the highest attrition rates.
    Make data-driven decisions to develop targeted retention strategies and improve employee satisfaction.
